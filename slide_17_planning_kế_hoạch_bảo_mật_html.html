18) Planning — Kế hoạch bảo mật

Objective

Security-by-Plan: gắn bảo mật với mốc, ngân sách, DoR/DoD

  • Đưa security vào **scope/WBS/ước lượng/lịch**; lặp theo increment.
  • Qua cổng bằng **evidence**: tài liệu, test reports, cấu hình.
  • Gates: SDR → Bug Bar → FSR.

Tham chiếu: Pressman Ch.3 (planning principles); Kohnfelder Ch.7 (Security Design Reviews).

Timeline

Lịch & Gates (SDR • Bug Bar • FSR)

Case tie‑in: đặt checkpoint bảo mật trước Sprint 3 (tiền‑SDR) để chốt trust boundaries & dữ liệu nhạy cảm.

Budget & Staffing

Ngân sách & nguồn lực test bảo mật

  • WBS: Threat modeling, SDR packet, SAST/DAST/secret scan, SBOM, hardening, chaos/negative tests.
  • Cost of quality (security): buffer review → fix → re‑test; lịch scan định kỳ (CI/CD), IaC policy‑as‑code.
  • Owner: SDR packet, threat model upkeep, triage tool findings, independent gate approver.
Secrets

Quản lý secrets (mức tối thiểu)

  • Không lưu secrets trong code; bật secret scanning trong CI.
  • Vault/KMS + rotation theo kỳ; audit access; deny‑by‑default.
  • SLI: thời gian xử lý rò rỉ; số secrets hard‑coded = 0.
DoR / DoD

Security in Definition of Ready/Done

Definition of Ready

  • Use case & data classification (PII/PHI?).
  • Acceptance criteria bao phủ abuse/misuse cases.
  • Luồng/dữ liệu mới → cập nhật threat model sơ bộ & kế hoạch test.

Definition of Done

  • AuthZ theo vai trò; log có cấu trúc, không lộ PII.
  • SAST/DAST/secret scan: **Critical/High = 0**; dependency có **SBOM** & policy pass.
  • Evidence cập nhật vào Evidence Store + liên kết tracker.
SDR Process

Quy trình SDR (rút gọn theo sách)

Tài liệu phải cụ thể (không ghi kiểu “store data securely”); reviewer độc lập giúp tăng khách quan.

Gate Policy

Checklist “Bug Bar (draft)” @ M4

Open bugs
  • Critical/High = 0
  • Medium có mitigation
  • Low có kế hoạch
Scans
  • SAST/DAST/Secret: 0 C/H
  • Container/IaC policy pass
Tests
  • Negative/abuse cases
  • AuthZ matrix
  • Fuzz/Canary endpoints
Docs & Evidence
  • Threat model cập nhật
  • SDR items đóng or accepted
  • SBOM + signatures
